# Driver Fatigue & Distraction Safety Monitor 🚗

A real-time **Computer Vision and Machine Learning** project for detecting driver fatigue, microsleep, and distraction using an in-cabin camera.

## 📌 Project Overview

The system will use facial landmarks to analyze the driver's eyes, mouth, and head movements. Features such as **Eye Aspect Ratio (EAR), Mouth Aspect Ratio (MAR), and head pose** will be used  to identify whether the driver is **Alert, Drowsy, or Distracted**.

An audio alert will be triggered when dangerous behavior is detected.

## 🛠️ Technology Stack

* Python
* OpenCV
* MediaPipe
* NumPy
* Pandas
* Scikit-learn
* SVM
* Matplotlib / Seaborn

## 🎯 Project Goal

To develop a lightweight real-time driver monitoring system that can help reduce accidents caused by **drowsiness and driver distraction**.
